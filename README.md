# Poultry Farm Analytics

MSc Data Science dissertation project investigating egg production prediction using machine learning and Power BI.

Methods: Linear Regression, Random Forest, XGBoost, hyperparameter tuning and SHAP explainability.

Dataset: Environmental egg production data containing 74 unique genuine observations after duplicate removal. Synthetic observations were generated for training augmentation.

Reproduction: Upload `Egg_Production.csv` into Google Colab, open `THESIS(2).ipynb`, check the `DATA_PATH` variable and run the cells in sequence.

Limitation: The project is a proof of concept and has not been validated for operational poultry farm deployment.
